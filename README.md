# Fake GPS (Android)

Простое приложение для подмены GPS-местоположения: выбираешь точку на карте (или вводишь координаты), жмёшь СТАРТ — телефон думает, что ты там.

## Сборка
1. Установи Android Studio.
2. File → Open → папка `FakeGPS`. Дождись Gradle Sync (Studio сама скачает Gradle и SDK 34).
3. Подключи телефон по USB с включённой «Отладкой по USB» и нажми ▶ Run.
   Или: Build → Build APK(s) → APK будет в `app/build/outputs/apk/debug/`.

## Настройка телефона (один раз)
1. Настройки → О телефоне → 7 раз нажать «Номер сборки» → включится режим разработчика.
2. Настройки → Для разработчиков → «Выбрать приложение для фиктивных местоположений» → **Fake GPS**.
3. Открыть приложение, разрешить доступ к местоположению и уведомлениям.

## Использование
- Тап по карте или перетаскивание маркера — выбор точки.
- СТАРТ — подмена включена (в шторке висит уведомление с кнопкой «Стоп»).
- Пока работает, можно тапать по карте — местоположение двигается сразу.

## Что важно знать
- Работает только на Android. На iPhone так нельзя без джейлбрейка.
- Подменяются провайдеры GPS и Network. Google Fused Location (Google Maps и многие приложения) обычно подхватывает их, но некоторые приложения проверяют флаг `isMock` и замечают подмену — например банки, Pokémon GO и т.п. Их правила могут запрещать подмену и банить аккаунт.
- Карта грузится из интернета (OpenStreetMap).
